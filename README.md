# quanttide-search-lab

量潮搜索工程实验室 — 实验性与原型项目汇聚地。

## 定位

实验室是正式流程之外「先试一试」的入口：试出来的方法回流到领域的档案、产品与流程，本仓不留正本、不承载事实源。

## 流程

1. **试**：把领域里还没落成东西的想法跑成原型，每个实验给出一条可判定的结论。例——日志里判断「纯粹的 RAG 对常见企业需求不顶用」，就跑两版对照：纯 RAG 与以元工程方法为基础的检索，同一批企业查询比结果。
2. **回流**：有效的方法写回领域的 `data/` 与 `docs/`；能长期跑的进 `apps/`，可复用的进 `packages/toolkit`；无效的删掉，不留痕。

目标不看仓库里有多少代码，看回流了多少方法、多少原型被判定该进 `apps/` 或该删。

## 实验

1. **本地全文搜索原型**（tantivy + jieba）：倒排索引 + BM25，零服务，中文接 jieba 分词。

   ```
   cargo run --release -- <仓库根> [索引目录] [查询...]
   ```

   实测本仓 6220 篇 Markdown，索引 + 查询 0.48 秒；两字词「索引」命中且排序正确（FTS5 trigram 在两字词上零结果）。选型、实测数据与 API 坑见 [docs/tech-notes.md](docs/tech-notes.md)。

2. **本机会话搜索行为研究**（2026-10-11）：分析 `apps/hermes-session-analyzer` 已有的 29550 条真实 AI 搜索事件，回答路线图「AI 怎么查」——89.1% 的搜索是 shell 命令而非搜索框，专用搜索查询中位仅 34 字符，连环搜占 43.9%。记录见 [docs/2026-10-11-hermes-session-analyzer.md](docs/2026-10-11-hermes-session-analyzer.md)，脱敏查询样例在 `data/search-queries-sample.jsonl`。

3. **搜索-读文件配对率实测**（2026-10-11）：回答评测的前置问题「日志里有多少搜索能配上真值」——去重后 25386 条事件总配对率 13.3%，专用搜索 51.0%、shell 仅 7.9%（grep 结果自带内容，不必开文件）；专用搜索配对子集约 1600 题足以支撑考题集。记录见 [docs/2026-10-11-pairing-rate.md](docs/2026-10-11-pairing-rate.md)，脱敏配对样例在 `data/paired-sample.jsonl`。

4. **语料关联与去重（corpus-linking）**：把 46 个领域仓的 Markdown 语料切片段、本地向量化（bge-m3，离线，22811 条），在向量上找重复、找关联、建索引——[索引的难点](docs/index-difficulties.md) 里「副本要等于真相」与「镜像去重」两条，这里用向量相似度重做了一遍。首轮查出 586 对高相似（阈值 0.90，涉及 946 条，其中跨领域 72 对）。脚本、报告与判据见 [examples/corpus-linking/](examples/corpus-linking/)。

### 能搜什么

- 任意目录下的 **Markdown 正文**（`.md`，递归时跳过 `.git`、`node_modules`、`target`、`.venv`），中英文都行：中文靠 jieba 分词，两字词「索引」能搜，英文词 `tantivy` 也能搜。
- 多词查询按 **OR** 合并、BM25 相关度排序取前 10。例：`"索引 新鲜度"` → 领域 README 与本仓 `tech-notes.md` 命中并排在最前。

### 不能搜什么

- **非 Markdown 文件**：代码、JSON、图片不进索引（遍历只收 `.md` 扩展名）。
- **文件名与路径**：查询只配了 body 字段，路径只存不搜——文件名叫 `…-deviation.md`，正文无此词就搜不到。
- **AND 与精确过滤**：多词是 OR，只含其中一个词的文档照样返回（实测只含「索引」的 `contract.md` 在「索引 新鲜度」查询里照样返回）；没有字段过滤、没有短语约束。
- **重复运行**：同一索引目录跑第二次会把全部文档再加一遍，副本翻倍、分数虚高（实测同一文件返回两行）——没有清空与增量更新。
- **镜像去重**：同一文件在 `domains/` 与 `assets/` 各占一席，前十名里成对出现。
- **可读性**：只回路径与分数，无高亮、无摘要片段，固定取前 10。
