# Roadmap

对本地量潮语料做三件事：找关联、找重复、建索引。三件共用同一条「文本 → 向量」管线。

## 目标

| 用途 | 干什么 | 衡量方式 |
| :-- | :-- | :-- |
| 找关联 | 哪些内容在讲同一件事 | 聚成簇，人工看簇有没有意义 |
| 找重复 | 同一内容多处写了、口径不一致 | 高分相似对，人工看是否真重复 |
| 建索引 | 想找某主题时能快速定位 | 拿真实主题查询，看召回 |

三件都不设先验指标——没有金标，验收方式是「跑出来给人看」：产出可复核（条数、分母、复跑命令），抽样人工判读，误报如实记录。

## 阶段

| 阶段 | 内容 | 产出 | 怎么算完 |
| :-- | :-- | :-- | :-- |
| 0 向量化 | 读本地语料 → 切片段 → 向量化 → 落盘 | 片段表 + 向量文件 | 片段条数可对数；同输入复跑结果一致 |
| 1 找重复 | 算片段两两相似度，取高分对 | 重复对清单（分值 + 双方出处） | 抽 30 对人工看，误报率如实记录 |
| 2 找关联 | 对向量聚类，取簇 | 簇清单（主题摘要 + 成员） | 抽几个簇人工看有没有意义 |
| 3 建索引 | 建向量索引 + 查询入口 | 可查询的索引与用法 | 拿真实主题查询，看召回对不对 |

阶段 0 是三件共同的闸门，先做完才有后续。
