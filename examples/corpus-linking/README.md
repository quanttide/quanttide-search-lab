# corpus-linking

对本地量潮语料做三件事：**找关联、找重复、建索引**。三件共用同一条「文本 → 向量」的管线。

## 数据

本地 `~/repos/quanttide/domains/`（各领域仓 `docs/*` 子模块已拉全）。全程离线，不依赖 GitHub。

## 三件事

| 用途 | 干什么 | 产出 |
| --- | --- | --- |
| 找关联 | 哪些内容在讲同一件事 | 主题簇 |
| 找重复 | 同一内容多处写了、口径不一致 | 重复对清单 |
| 建索引 | 想找某主题时能快速定位 | 可查询的向量索引 |

阶段计划见 [ROADMAP.md](ROADMAP.md)，执行清单见 [TODO.md](TODO.md)。
